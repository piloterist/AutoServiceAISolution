# Заявки с panmotors77.ru в CRM: что должен сделать программист сайта

Сайт выгружен из Webflow, формы шлют заявки на `/mail.php` (AJAX, multipart), фото идут там же полем `file[]`.
Тестовая заявка 18.11.2026 в 12:04:13 МСК дала на сайте **HTTP 500 с пустым телом**, и **до CRM запрос
не доходил** (в журнале CRM за это время нет ни одного обращения к `/api/v1/leads/intake`).
Поэтому нужно: (1) починить `mail.php`, (2) добавить в него отправку в CRM, (3) поправить `mail.js` и разметку.

CRM уже понимает форму этого сайта целиком: имена полей как есть (`Phone number`, `Name`, `Форма`, `Страница`,
`advchannel`, чекбоксы `Bamper`, `Kapot`, ..., `Budget`, `Summa`, `Gift`, `Evakuator`, `message`),
пустой `file[]` и фото прямо в запросе. Менять поля формы не нужно.

## 1. Найти причину HTTP 500 в `mail.php`
Посмотрите журнал ошибок PHP на хостинге на 12:04:13 МСК 18.11.2026 (запрос `POST /mail.php`).
Наиболее вероятные причины:
- обращение к `$_FILES['file']` без проверки: квиз без фото шлёт пустой `file[]` (имя пустое, размер 0);
- в `mail.php` попал код с другого сайта (`send/crm.php`, `tmp_files`, поля `user_phone`, `files`, `folder`),
  которого здесь нет;
- ошибка версии PHP.

Проверка файла: `if (!empty($_FILES['file']['name'][0]) && $_FILES['file']['error'][0] === UPLOAD_ERR_OK)`.

## 2. Отправка в CRM
1. Положите `crm_forward.php` рядом с `mail.php`.
2. В файле впишите токен приёма заявок (выдаёт администратор CRM, в чат и git не слать).
3. В `mail.php` после приёма заявки и **до** ответа посетителю:

```php
require_once __DIR__ . '/crm_forward.php';

// ... проверка полей, отправка письма (если нужна) ...

crm_forward_lead($_POST, $_FILES);   // ошибка CRM не должна ломать форму
echo 'success';                       // mail.js считает успехом только ответ ровно success
```

Функция сама пропускает пустой `file[]`, ограничивает размер и число фото (10 шт., 12 МБ), глушит все
исключения и пишет в журнал PHP одну строку на заявку: `CRM lead: http=201 photos=N`.
`http=201` значит, что CRM заявку приняла. `401` значит неверный токен, `422` нет телефона, остальное
(0, curl_error) значит, что хостинг не достучался до CRM.

Проверка связи с хостинга сайта (токен подставьте сами):

```
curl -i -X POST https://piloterist-autoserviceaisolution-8706.twc1.net/api/v1/leads/intake \
  -H "Authorization: Bearer ТОКЕН_ПРИЁМА" \
  -d "Phone number=+7 (000) 000-00-00" -d "Форма=Кузов" -d "Страница=/test"
```

Ожидается `HTTP/1.1 201 Created`.

## 3. `mail.js`: ошибки не должны зависать
Сейчас при ответе сервера не `success` (в том числе 500) кнопка навсегда остаётся «Идёт отправка...»:
в запросе нет обработчика `.fail()`. Что поменять (пример под jQuery, адаптируйте под реальный файл):

```js
// 1) Отправлять ту форму, которую заполнил посетитель, а не искать форму по id:
$(document).on('submit', 'form', function (e) {
  e.preventDefault();
  var $form = $(this);
  var $btn = $form.find('[type=submit]');
  var btnText = $btn.val();
  $btn.val('Идёт отправка...').prop('disabled', true);

  $.ajax({
    url: '/mail.php', type: 'POST', data: new FormData(this),
    processData: false, contentType: false
  }).done(function (answer) {
    if ($.trim(answer) === 'success') { /* показать успех, как сейчас */ }
    else { fail(); }
  }).fail(fail);   // 2) ошибка сервера (500 и т. п.)

  function fail() {
    $btn.val(btnText).prop('disabled', false);   // вернуть кнопку
    $form.siblings('.w-form-fail').show();       // показать сообщение об ошибке
  }
});
```

## 4. Разметка и скрипты
- У двух форм одинаковый `id="wf-form-request-form"` (рассрочка и «Оставить заявку»): сделать id уникальными,
  иначе форма «Оставить заявку» отправляет данные не своей формы.
- На `/quiz` не подключён скрипт коллтрекинга, поэтому падает `ReferenceError: umtz_data is not defined (custom.js:113)`
  и канал рекламы (`advchannel`) не попадает в заявку. Подключить скрипт и/или проверить `typeof umtz_data !== 'undefined'`.
- jQuery подключён дважды (3.4.1 и 1.11.3 с jquery-migrate): оставить одну версию.
- Сайт открывается и с `www`, и без `www`: сделать редирект на один адрес.

## 5. Как проверить, что всё заработало
1. Отправить одну тестовую заявку на сайте (телефон `+7 (000) 000-00-00`, имя «ТЕСТ»).
2. В журнале PHP должна появиться строка `CRM lead: http=201`.
3. В CRM в «Заявки с сайта» появится заявка, в колонке «Сайт» адрес `panmotors77.ru`.
